# Combat Simulator / Sub game

The idea here is to setup the characters, effects, Items, and entire combat system.
These Systems should be modular/isolated from eachother.


## Goals
 - Create all basic systems that work together for a combat system
 - Make the networking for this. (It should work in both singleplayer or multiplayer)
 - Networking should be very optimized (dont want random packets flying around taking up our network)
 - Completely functional game (mostly for testing new skills and whatnot)
